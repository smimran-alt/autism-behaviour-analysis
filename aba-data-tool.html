ABA Data Studio

Record baseline and teaching trials, calculate session outcomes and view progress—without creating an account.

Free browser-based tool · No paid API

1. Session details

Use an anonymous learner code rather than a child's name. Avoid entering identifiable or sensitive information.

2. Recording guide

Select one result for each trial. Blank trials are excluded from the denominator.

Response codes

I — Independent: correct response without a prompt.
P — Prompted: correct response with assistance.
N — Incorrect / no response: not independently correct.
— — Not recorded: trial excluded from calculations.

This tool uses independent correct ÷ recorded trials × 100 for the independent percentage. A prompted-correct percentage is shown separately. Your clinical protocol may define success differently.

A three-day baseline can be tracked by saving one baseline session per day. Three days is a configurable practice example, not a universal clinical requirement.
